## featured projects

### `raspberry-pi-smart-mirror`
A lightweight smart mirror dashboard for Raspberry Pi 3 and a 24-inch display, designed with dynamic greetings, weather, Spotify, calendar integration, sensor support, presence detection and LED control.

### `physical-raspberryPi-network-lab`
A physical enterprise-style networking lab built with an Aruba 2930F Layer 3 switch and multiple Raspberry Pi nodes providing DHCP, DNS and web services across segmented VLANs.

### `enterprise-network-packet-tracer`
A simulated enterprise network project focused on VLAN design, routing, DHCP, DNS, SSH access, ACLs and troubleshooting.
